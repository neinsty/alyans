# 3D SLAM и локализация в реальном времени для Unitree Go2 (Команда «Альянс»)

Программное решение для построения трёхмерной карты помещения и устойчивой локализации квадропедального робота Unitree Go2 в условиях динамических препятствий, резких поворотов и неоткалиброванного IMU.

## Структура решения
* `hackathon/ros2_ws/src/go2_slam/go2_slam/map_builder.py` — узел построения 3D-карты (`VoxelGrid` 5 см, одометрия + Point-to-Point ICP, статистическая фильтрация выбросов).
* `hackathon/ros2_ws/src/go2_slam/go2_slam/localizer.py` — узел локализации в реальном времени (прогноз по кинематической одометрии `/utlidar/robot_odom` + Scan-to-Map ICP с порогом отсечения динамических объектов `0.25 м`).
* `hackathon/ros2_ws/map.pcd` — построенная 3D-карта помещения (1.9 МБ).
* `hackathon/ros2_ws/slam_view.rviz` — конфигурация визуализации RViz2.
* `hackathon/ros2_ws/timings.txt` — замеры производительности пайплайна локализации.
